# SD — işlem kodları (referans)

| İşlem | İş |
|---|---|
| VA01 / VA02 / VA03 | Satış belgesi yarat / değiştir / görüntüle |
| VA21 / VA22 / VA23 | Teklif yarat / değiştir / görüntüle |
| VA05 | Satış belgesi listesi |
| VL01N / VL02N / VL03N | Çıkış teslimatı yarat / değiştir / görüntüle |
| VL10A / VL10B / VL10G | Vadesi gelen teslimatlar (toplu) |
| VL06O | Çıkış teslimatı izleme |
| VL09 | Mal çıkışı iptali |
| LT03 / LT12 | Transfer siparişi (WM toplama) |
| VF01 / VF02 / VF03 | Fatura yarat / değiştir / görüntüle |
| VF04 | Vadesi gelen faturalar |
| VT01N / VT02N / VT03N | Nakliye yarat / değiştir / görüntüle (LE-TRA) |
| VKM3 / VKM1 | Kredi blokajı listesi |
| VOV8 / VOV7 | Belge türü / kalem tipi uyarlaması |
| SM13 | Güncelleme kayıtları (V1/V2 hataları — ST22'de dump olmayan kayıt hataları burada: `enhancements.md`) |
| SE16N | Tablo görüntüleme (salt-okur; kişisel veri kuralına dikkat) |

> ⚠ İşlem kodu yaratma (SE93) operatör işidir: paketin Z işlem kodlarını operatör açar.
